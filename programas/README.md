# Programas del curso

Aquí está cada programa del curso, por lección, listo para abrir y ejecutar.

- Los archivos `.salida.txt` muestran lo que imprime cada programa.
- Los `.error-esperado.txt` son ejemplos que a propósito fallan: unos no compilan y otros terminan con un
  `panic`. La lección enseña a leer ese error y a corregirlo.

Para ejecutar uno, entra a la carpeta de su lección y corre `go run figNN_NN.go`. Los que leen un archivo de
datos lo traen en la misma carpeta.

`revisor/` es el proyecto completo que se construye en las lecciones 5 a 7, con sus pruebas (`go test ./...`).

Estas carpetas se generan a partir de las lecciones: no se editan a mano.
